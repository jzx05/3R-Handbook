# 深度笔记

这个目录放**人工/agent 撰写**的方法解读、复现记录和失败模式分析。
自动抓取的论文条目在 [`papers/`](../papers/README.md)，不要在这里重复索引。

## 怎么写

1. 复制 `_template.md` 为 `notes/<short-name>.md`（短名用小写连字符，例如 `gluemap.md`）。
2. 在 `notes/README.md` 的表格里加一行。
3. 至少读摘要 + 方法 + 实验设置；有条件就读代码。
4. 每个数字都能在原文找到，并附链接/页码/表格编号。

## 状态约定

- `draft`：结构齐了，数字未核完
- `verified`：关键数字已回原文核对
- `reproduced`：跑过代码/权重，记录了环境与偏差
- `stale`：论文/代码已更新，笔记需要复核
